# Free external AI learning — verified sources and reuse boundaries

These links are resources for learners, not re-hosted or rebranded third-party materials.

| Provider | Official resource | Access / intellectual-property limitation |
| --- | --- | --- |
| MIT OpenCourseWare | https://ocw.mit.edu/ | Free access; many materials governed by Creative Commons with non-commercial restrictions. Check each licence before adapting. |
| MIT Sloan | https://ocw.mit.edu/courses/15-773-hands-on-deep-learning-spring-2024/ | Free course material for advanced students. Original creator retains attribution rights. |
| Stanford | https://cs229.stanford.edu/ | Public machine-learning course information/materials. Free viewing does not imply redistribution rights. |
| University of Helsinki / MinnaLearn | https://www.elementsofai.com/ | Free self-paced introductory course; use the external site and review optional credential terms. |
| Google for Developers | https://developers.google.com/machine-learning/crash-course | Free interactive ML modules. Do not assume Google's materials have an open licence. |

Before linking a resource in an assessment pathway, check that it is still available, whether account signup or payment for credentials is required, and whether the resource suits the learner's technical background.
