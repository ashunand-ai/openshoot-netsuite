# Video production script: Ask Oracle to explain an authorised saved search

**Format:** 75–90 second narrated screen recording; 16:9 master and 9:16 cutdown.  
**State:** Script ready; footage/rendering not produced.  
**Audience:** CFOs and analysts  
**Source:** https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_1175030259.html

## Editorial guardrails

Do not assume Ask Oracle is available in every account; it is role-gated and rollout-dependent. No copyrighted Oracle logo/footage without appropriate permission. Use authorised UI capture or clearly labelled illustrations; never invent transaction balances or depict synthetic data as real.

## Storyboard and voiceover

| Approx. time | Narration | Visual direction |
|---|---|---|
| 0–10s | “Your saved search can become a plain-English finance briefing without building a new dashboard.” | Title card: Oracle NetSuite 2026.2 August; include ‘features vary by account’. |
| 10–25s | “First check your account version, permissions and prerequisites. Do not assume the feature is enabled for every customer.” | On-screen prerequisite checklist; synthetic demo identifiers only. |
| 25–65s | “Confirm Ask Oracle has been enabled for the role; availability may be phased. Find a saved search you already have permission to access. Reference the exact saved-search title or script ID in an Ask Oracle question.” | Sequential overview cards or authorised screen captures; pause briefly at each action. |
| 65–80s | “Ask for a summary, an explanation of the filters used, and any limitations. Reconcile totals and filters against the saved search displayed in NetSuite. Avoid acting on financial outputs until an accountable reviewer checks the numbers.” | Verification card with a sample evidence register and a clear ‘stop if blocked’ marker. |
| 80–90s | “Get the free step-by-step guide and validation checklist on GitHub. Complex cases still need expert review.” | GitHub project URL; tag ‘OpenShoot tutorial, independent, not Oracle-endorsed’. |

## Recording checklist

- Confirm current Oracle docs and account release immediately before recording.
- Record exact menu labels from an authorised demo instance; do not improvise unverified UI.
- Replace all account IDs, balances, customers and credentials with synthetic examples.
- Verify captions and spoken instructions match the linked lesson.
- Get a NetSuite functional reviewer to sign off any financial, security or production-impact guidance.
- Publish only after source review and footage QA; then change catalog status from `scripted` to `published`.
