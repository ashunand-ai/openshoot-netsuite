# Video production script: Use Oracle's 48 NetSuite SuiteSkills before buying custom AI workflows

**Format:** 75–90 second narrated screen recording; 16:9 master and 9:16 cutdown.  
**State:** Script ready; footage/rendering not produced.  
**Audience:** Finance leaders and administrators  
**Source:** https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_4123813814.html

## Editorial guardrails

The 48 skills are Oracle's work, not OpenShoot code; do not copy Oracle-owned skill code. No copyrighted Oracle logo/footage without appropriate permission. Use authorised UI capture or clearly labelled illustrations; never invent transaction balances or depict synthetic data as real.

## Storyboard and voiceover

| Approx. time | Narration | Visual direction |
|---|---|---|
| 0–10s | “Before you pay for another bespoke AI workflow, check the 48 NetSuite SuiteSkills Oracle already provides.” | Title card: Oracle NetSuite 2026.2; include ‘features vary by account’. |
| 10–25s | “First check your account version, permissions and prerequisites. Do not assume the feature is enabled for every customer.” | On-screen prerequisite checklist; synthetic demo identifiers only. |
| 25–65s | “Verify whether Oracle's SuiteSkills plug-in is available in your supported AI client and account. Review its five categories: Customers & Sales, Finance, Onboarding, Operations and Workforce. Select a low-risk, read-only use case such as a finance summary or pipeline review.” | Sequential overview cards or authorised screen captures; pause briefly at each action. |
| 65–80s | “Confirm that the connected NetSuite role has access to the required data. Run the available workflow with non-sensitive test data, verify the underlying figures in NetSuite, and document differences. Use explicit approval for any workflow that proposes a record change.” | Verification card with a sample evidence register and a clear ‘stop if blocked’ marker. |
| 80–90s | “Get the free step-by-step guide and validation checklist on GitHub. Complex cases still need expert review.” | GitHub project URL; tag ‘OpenShoot tutorial, independent, not Oracle-endorsed’. |

## Recording checklist

- Confirm current Oracle docs and account release immediately before recording.
- Record exact menu labels from an authorised demo instance; do not improvise unverified UI.
- Replace all account IDs, balances, customers and credentials with synthetic examples.
- Verify captions and spoken instructions match the linked lesson.
- Get a NetSuite functional reviewer to sign off any financial, security or production-impact guidance.
- Publish only after source review and footage QA; then change catalog status from `scripted` to `published`.
