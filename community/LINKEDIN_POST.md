# Public launch post (accurate for v0.1)

Oracle's NetSuite AI Connector is changing what's possible with ERP and AI.

With Oracle's native MCP Standard Tools and the documented 2026.2 SuiteSkills plug-in, the underlying connectivity and business skill building blocks are increasingly available from Oracle itself.

But every NetSuite implementation is different: OneWorld subsidiaries, roles, custom fields, scripts, workflows and approvals all matter.

So I'm releasing **OpenShoot NetSuite v0.1**, free and open-source.

It's a practical starting point, not a claim to have rebuilt Oracle's connector. You can run the offline readiness checker today to validate an account ID format, generate a candidate MCP endpoint and produce an administrator checklist. The repository also includes a reusable Agent Skill, tests and a deployment guide.

**What's next:** permission-aware live tool discovery and implementation-specific validation, subject to authorised access.

The goal is to reduce unnecessary paid setup friction while keeping complex ERP work in expert hands. Fork it, review it and contribute.
